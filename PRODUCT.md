# OpenModels
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and purpose
Developers consuming archived comma models: browse the directory, pin a catalog snapshot, and
install verified weights. Maintainers publish the archive and its static directory.

## Confirmed workflow
Browse models by published name, alias, class or target; open a model page for its exact source
configurations; download a recipe for the SDK. The Developers page documents the SDK and CLI.

## Constraints
Static GitHub Pages; no backend or browser Python runtime required. Preserve schema 1, exact
document identity, source contexts, missing settings, and existing downloads. Consumers own
support policies, installation, qualification and activation. Paginate listings at 30 results and
load search on demand.

## Brand commitments
The approved direction is a technical instrument panel: graphite surfaces, crisp divisions,
compact readable controls, monospace data/code, cyan selection and amber missing information.
Light/dark themes, keyboard access and a stacked mobile workflow are required.
