# Security policy

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button.
Do not open a public issue for a vulnerability that could alter catalog data, execute code in
the indexer, or cause clients to install an unverified model.

If private reporting is unavailable, open an issue containing no vulnerability details and ask
the maintainer to arrange a private channel.

The supported version is the current `main` branch. Reports should include a minimal reproducer
and the affected commit.
